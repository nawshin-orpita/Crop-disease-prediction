🥔 Potato Leaf Disease Prediction
🌿 Detecting Early Blight, Late Blight, and Healthy Leaves Using Deep Learning
📖 Overview

This project focuses on automated detection of potato plant diseases using deep learning.
The system can classify leaf images into three categories — Early Blight, Late Blight, and Healthy — helping farmers and researchers identify diseases at an early stage to prevent crop loss.Then deploy the model.

The model uses image data and machine learning techniques to predict the condition of potato leaves efficiently and accurately.

🎯 Objectives
1. Detect Early Blight and Late Blight in potato leaves

2.Classify Healthy leaves separately

3.Assist in early diagnosis for better crop management

4.Provide an accurate and automated solution using image classification



🪴 Dataset

The dataset used for this project (https://www.kaggle.com/datasets/hafiznouman786/potato-plant-diseases-data)
